The shared EVM/TRE/SVM correctness verifier has passed its scoped component controls and independent review. This packet preserves the implementation and its corrections across separate source epochs. **Zero actual native cases are accepted.** Runtime builds, exact case/tool/image/capacity approval and real chain/checkpoint/SQL/600-second/restart evidence remain required before a family can pass.

The [archive manifest](../../zig/bench/results/shared-native-verifier-controls/manifest.json) records155 deterministic lossless gzip members. The [verification receipt](../../zig/bench/results/shared-native-verifier-controls/verification.json) records exact decoded-byte/SHA checks, source-snapshot verification and independently rehashed helper product pins. It contains no compiled binary, database, WAL or cache copy.

These counts overlap across epochs and imports. They are not a total of unique behavioral checks, benchmark samples or real-node acceptance. Existing raw results, logs, commands, failures, source copies and review findings are archived unchanged; later fixes do not rewrite earlier statuses.

The latest verifier retains exact native wire/message IDs, canonical receipt membership, continuous per-ID early Confirm/SubmittedBySelf presence, own600-second hold and observed retirement by630 seconds. Same-database restart checks bind actual new child PID/start/executable/config, retain signed identity/context/generation/intent and forbid additional submissions. Stopped readers require actual parent wait receipts and run the immutable canonical Rust oracle before the read-only native-row reader. Initial null context remains observed rather than independently recomputed configuration authority.

Canonical PostgreSQL checks preserve existing linked-ID/value/fee predicates and add block/hash/height/transaction/index/log/emitter predicates. SVM uses authenticated account stream sequence, not instruction ordinal, and preserves Source wrong-IGP payment0 normalization. Four SQL controls reject105 right-ID/wrong-coordinate mutations using an actual relational SQLite engine and bytea shim. This is predicate evidence, not PostgreSQL execution. EVM sender and matching prepare sender must equal independently supplied reviewed public payer addresses; native TRE separately verifies its TriggerSmartContract signature/wire and wallet/solidity confirmation. EVM configured depths0/1/2 and a second canonical header fence are checked.

Empty checkpoint objects are accepted only for an actual configured zero-leaf validator origin with independently verified metadata bytes, canonical domain/counts and no signed objects. A positive origin cannot use that path; no nonexistent signature is credited. Original peer order/count/duplicate equivalence and all effective default/custom endpoint fields remain intercepted. Source-proven explorer metadata is inert and privacy-redacted; it does not gain transport authority.

The final independent readback closed four verifier findings. The separate advanced SVM production log-index defect was fixed and reviewed in its own packet; this archive’s verifier deliberately expects Source sequence semantics. The then-known Radix split-readiness issue was outside the accepted seven-file shared scope and remains explicitly recorded in the historical review. Actual family eligibility must use its own final reviewed source closure.

That equality is legitimate: native Starknet scenario code is reached through the test binary, while the normal helper excludes it. Both new products and both preserved older helper products were independently rehashed. Their exact complete hashes and sizes are in the archived product manifests; executables were not copied.
