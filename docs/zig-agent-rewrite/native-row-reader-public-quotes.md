The fixture writes a Starknet scalar quote, a full 64-byte Sealevel identity, a two-member shared Starknet group and an Aleo process with a null row target and a resolved Prepared target. Stored group gas weights are 1 and 3; quote costs exceed `2^240`. Independent Python arithmetic verifies exact decimal costs, floor allocation and explicit rounding dust. These are stored allocation weights, **not original scalar RPC estimate provenance**. The fixture does not exercise real Starknet `prepareBatch` or SDK signing.

Both modes hold the actual Zig RocksDB writer open and prove the new reader refuses its lock. They then reap it with exit 0, run the immutable old canonical oracle first, and run the native reader sequentially. Independent Rust message vectors, full identity halves, private-data omission, exact expenditure markers, wrong context/nonce/missing ID, resolved-recipient rejection and actual Zig read-only reopen all pass. Every database byte remains unchanged after the old canonical readback. The synthetic confirmation clock retains the normal 600,000 ms policy but earns **zero elapsed hold credit**.

The reader extracts public Starknet data from bounded raw JSON, retaining exact u256 decimal values without floating-point conversion. It rejects malformed scalar/group fields, duplicate normalized IDs, oversized manifests, zero total weights and mismatched own-member authority or quotes. Only Aleo process rows with a null stored target may use a non-null resolved Prepared target; other target bindings remain exact. No authorization, intent payload or signed bytes are printed.
