# Independent metadata lifetime and cancellation review

No remaining blocking lifetime/cancellation finding in the reviewed production paths. Two concrete issues found during this review were fixed by the implementation owners and independently rechecked. This is scoped closure; the global Source/full-suite/benchmark gates remain with the parent.

## Findings resolved during review

1. **P2 — stopped business leaves could publish a late terminal metric.** `Builder.nodeTyped` published its terminal metric when an uncancellable callback returned, before `JobState.execute` noticed operation cancellation and discarded its output. An early-threshold aggregation could therefore retain no result yet count its stopped trailing CCIP build. The metadata owner added owner/ancestor cancellation checks after the callback and before both success/failure publication (`zig/src/relayer/metadata.zig:445`, `:463`, `:471`). Success bytes are freed on this branch. The actual blocking callback regression at `zig/src/metadata_parallel_delegated_tests.zig:1585` holds a trailing leaf until threshold return/stop, then releases it and requires zero terminal events. Independent final central run passed this case and the existing pre-stop success/verification-rejection semantics.
2. **P2 — native cached default lookups lacked the post-fetch clock hook.** `CachedSource.defaultNow` prefers an underlying `defaultIsmNow` method, but the native Source did not implement it. Native selector-driven misses could insert using the old lookup timestamp despite the synchronous Factory classifier already sampling fresh time. Protocol owner added `NativeSource.defaultIsmNow` (`zig/src/agents/destination/source_metadata.zig:66`), using raw Instant milliseconds exactly like Factory.active_cache_ms. It has no I/O or retained stack context. The native SVM suite was rerun after this additive method. Actual EVM retained-clock/TTL behavior is independently covered by the late physical-read fixture below; the native method/domain match was inspected directly.

## Lifetime and ownership closure

- **Owned cancellation ancestry:** Operation.create retains its parent CancelLink; final release destroys owned jobs/results/message/app context/attempt/memo before releasing that parent (`metadata.zig:174`, `:269`). The descendant-to-ancestor graph is acyclic in the production construction paths. Native Source forks retain links and release them on every constructor error and normal teardown (`source_metadata.zig:90`). Rebinding a job Source to its own Operation creates an intentional temporary ownership edge which is broken by JobState.finish closing Source BEFORE releasing its job reference (`metadata.zig:67`). That ordering prevents a retained self-cycle and keeps cancellation storage alive during client/session destruction.
- **Borrowed caller flags detach before return:** parentCancelled reads parent_cancel under the same mutex used by stop to clear it (`metadata.zig:218`, `:311`). Ancestor polling runs outside the child lock. start failures call stop through errdefer; all normal wait/build exits stop before releasing the caller reference. The explicit parent-cancel test poisons the caller flag after the Builder thread joins, drains retained children, and checks that no additional effects occur.
- **Assisted nested waits:** wait/next check owner and ancestor cancellation before assisting more jobs (`metadata.zig:320`). NativeSource.check and scoped inline LeafBuilder carry retained ancestry into nested SVM builders (`source_metadata.zig:56`, `:148`). The actual nested SVM fixture cancels twenty suspended quorum attempts and joins in less than its two-second bound, with no terminal completion metrics or retained read/output bytes.
- **Start/submit/PIO/OOM:** fork acquisition precedes job-ref/submit transfer; rejected submission drops the untransferred ref and stops the operation. Unsubmitted forks remain owned by final Operation.release. PendingReadIo requeues the same job and source; terminal/cancel paths close it once. Flat and nested allocation sweeps, observation-queue saturation, and inline-fork all-allocation sweeps passed. The business-job submit rejection branch was also inspected directly; independent saturation execution targets the detached observer submission path.
- **Detached latest jobs are independent of business cancellation:** startObservation owns validator/app-context copies and an independent source fork, binds Executor.stopToken, and explicitly clears business ancestry before submit (`metadata.zig:726`). Shutdown signals that heap-stable global token before joining executor threads (`metadata_parallel.zig:171`). The callback checks it before publication after a successful late read (`metadata.zig:881`). Both global-stop and completed-operation-cancel fixtures passed; complete configured validator sets, including absent -1 members, survive only business cancellation.
- **Inline decoded arrays and scoped adapters:** native Source.fork copies inline validators (`source_metadata.zig:100`); persistent builders never retain the scoped inlineLeaf adapter or decoded Spec arrays. InlineExecutor joins every scheduled child before releasing its stack cancel/jobs/spec borrows (`sealevel/inline_metadata.zig:33`). Source fork OOM tests explicitly require link refs return to one after every partial allocation and zero after clearing the root.
- **No stack DefaultContext callback in retained production forks:** EVMPreparer's DefaultContext is used only by synchronous strict classification; CachedSource options no longer retain it (`agents/relayer/evm_prepare.zig:460`, `:478`). EvmSource copies the role-owned ObservationClock value into each fork (`relayer/evm_source.zig:39`), and CachedSource.defaultNow calls the fork's method (`relayer/cached_source.zig:127`). The late-clock regression retains an actual physical default lookup across parent Source/client/wrapper frame return, rejects an expired fallback callback, observes exactly one owned clock read, and checks the full 600000ms TTL.
- **Borrowed role owners outlive callbacks:** production TaskSet joins destination workers, drains the metadata executor, then destroys lanes, observation manager, caches, origin history and HTTP resources (`agents/relayer_task.zig:1111`). Thus observer, clock, history and transport contexts remain valid through detached callbacks. These APIs still require callers outside this role owner to preserve that same lifetime ordering.
- **Replay/leaf identity:** shared VisitMemo survives retained root/nested jobs; it records one full latest observation and one terminal leaf event per logical path. Independent twenty-quorum/verification-replay tests and the native fixture with two distinct identical configured leaves pass. Late refused outputs cannot veto a threshold that has already stopped their operation; pre-stop refusal behavior remains covered.
